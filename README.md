# SifatAI — prototip sayt

To'qimachilik fabrikalari uchun matodagi nuqsonlarni sun'iy intellekt yordamida aniqlash tizimining sayti. O'zbek va ingliz tillarida.

- Hero qismida brauzerda ishlaydigan taftish simulyatsiyasi (canvas)
- Nuqson turlari, 4 balli tizimdagi rulon hisoboti (interaktiv), narxlar

Oddiy HTML, CSS va JavaScript, build kerak emas. Vercel'da "Framework Preset: Other" bilan deploy qilinadi.

Barcha raqamlar va rulon ma'lumotlari namuna.
